# Estudos-Java

[![Linguagem](https://img.shields.io/badge/Language-Java-orange.svg)](https://www.java.com/)

## Descrição

Este repositório tem como objetivo documentar e armazenar meus estudos da linguagem de programação Java durante o curso de Análise e Desenvolvimento de Sistemas (ADS) na Faculdade FATESG. Aqui você encontrará exemplos de código, exercícios práticos e pequenos projetos desenvolvidos ao longo do curso.

## Conteúdo

O repositório está organizado da seguinte forma (esta seção pode evoluir conforme seus estudos):

* **`fundamentos/`**: Códigos e exemplos relacionados aos conceitos básicos da linguagem Java (tipos de dados, operadores, estruturas de controle, etc.).
* **`orientacao-objetos/`**: Exemplos e exercícios sobre os pilares da Programação Orientada a Objetos (classes, objetos, herança, polimorfismo, etc.).
* **`estruturas-de-dados/`**: Implementações e estudos sobre arrays, listas, mapas e outras estruturas de dados em Java.
* **`manipulacao-de-arquivos/`**: Códigos para leitura e escrita de arquivos em Java.
* **`excecoes/`**: Exemplos de tratamento de exceções.
* **`projetos/`**: Pequenos projetos práticos desenvolvidos durante o curso.
* **`anotacoes/`**: Arquivos de texto ou Markdown com minhas anotações e resumos sobre os tópicos estudados.

## Tecnologias Utilizadas

* [Java SE Development Kit (JDK)](https://www.oracle.com/java/technologies/javase-downloads.html)
* [NetBeans com extensão Java](https://netbeans.apache.org/front/main/index.html)


## Como Utilizar

Você pode explorar o conteúdo deste repositório para ver exemplos de código e acompanhar meu progresso. Sinta-se à vontade para clonar o repositório e executar os códigos localmente, caso deseje.
